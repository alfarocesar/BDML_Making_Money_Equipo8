\section{Introducción}

Este documento detalla el desarrollo de un modelo predictivo para la estimación de precios de venta de propiedades residenciales, enfocado en el barrio Chapinero de Bogotá, Colombia. La problemática se enmarca en la necesidad de una startup dedicada a la compraventa de bienes raíces de optimizar sus operaciones de adquisición, minimizando el riesgo de sobrestimación en la valoración de activos.

La precisión en la predicción de precios es crítica para el éxito financiero en el sector inmobiliario. Un ejemplo notable es el caso de Zillow Offers, que resultó en pérdidas de aproximadamente 500 millones de USD y la reducción del 25\% de su fuerza laboral debido a algoritmos que sobrestimaron el valor de las propiedades \cite{zillow2021}. Este caso resalta los riesgos inherentes a modelos predictivos imprecisos.

El fundamento conceptual del modelo se basa en la teoría de precios hedónicos, propuesta por Rosen \cite{rosen1974}. Esta teoría establece que el precio de una propiedad (\(P_i\)) es una función de sus características estructurales, de vecindario y amenidades locales: 
\[
P_i = f(c_{i1}, c_{i2}, ..., c_{in})
\]
Dado que Rosen no especifica una forma funcional para \(f\), esto permite explorar modelos de aprendizaje automático. Los precios hedónicos son precios implícitos de atributos revelados a partir de observaciones del mercado.

El modelo desarrollado busca estimar precios de oferta de viviendas en Chapinero, apoyando decisiones de compra de una startup, minimizando errores que puedan llevar a sobrevaloraciones, como ocurrió con Zillow Offers.

Los datos provienen de Properati, y ante la escasez de información específica para Chapinero, se enriquecieron mediante ingeniería de características desde fuentes externas y descripciones textuales. Se anticipa que el modelo \textit{Extreme Gradient Boosting} (XGBoost) ofrecerá resultados robustos y precisos, dada su eficacia con relaciones no lineales y datos de alta dimensionalidad \cite{chen2016xgboost}.

\section{Adecuación de los Datos}

La ausencia de una cobertura exhaustiva de inmuebles específicamente ubicados en Chapinero podría introducir sesgos geográficos y limitar la capacidad del modelo para generalizar dentro del área de estudio. Para mitigar este riesgo, se incorporaron fuentes de datos complementarias y se desarrollaron nuevas variables a partir de procesamiento espacial y textual.

Los datos utilizados consisten en dos bases proporcionadas por Properati: \texttt{train.csv} (con precio) y \texttt{test.csv} (sin precio). Ambas contienen información estructural del inmueble (número de habitaciones, baños, área construida), su ubicación geográfica (latitud y longitud), y una descripción textual libre.

Adicionalmente, se diseñó un pipeline de enriquecimiento de datos que generó nuevas variables a partir de:

\begin{itemize}
    \item \textbf{Texto descriptivo}: Se procesaron las descripciones mediante técnicas de limpieza, normalización y extracción de patrones, con el objetivo de capturar señales latentes de lujo (\texttt{nivel\_premium}), completitud funcional del inmueble (\texttt{nivel\_completitud}) y urgencia de venta (\texttt{nivel\_venta\_inmediata}).
    \item \textbf{Variables espaciales}: Usando las coordenadas geográficas, se calcularon distancias mínimas a puntos de interés clave en la zona de Chapinero, Bogotá, utilizando datos de OpenStreetMap (OSM). Las variables incluidas fueron: \texttt{distancia\_parque}, \texttt{distancia\_universidad}, \texttt{distancia\_estacion\_transporte} y \texttt{distancia\_zona\_comercial}.
    \item \textbf{Filtrado geográfico}: Se utilizó \texttt{getbb()} para obtener un \texttt{bbox} georreferenciado de Chapinero y filtrar las amenidades relevantes mediante consultas específicas a OSM con \texttt{osmdata}.
\end{itemize}

Los datos fueron procesados para garantizar consistencia estructural, eliminar valores extremos e imputar valores predeterminados cuando no se encontró información espacial (por ejemplo, una distancia fija de 5km cuando no se hallaron parques). Esta fase de adecuación permitió aumentar la calidad de las variables predictoras y fortalecer la robustez del modelo en escenarios urbanos reales.

Todas las transformaciones se realizaron con funciones reproducibles y documentadas en el script \texttt{02\_spatial\_vars.R}, asegurando trazabilidad y escalabilidad del flujo de trabajo para otros sectores urbanos o ciudades.

\subsection{Construcción de la Muestra}

La muestra se construyó mediante adquisición, limpieza y transformación de datos provenientes de Properati para Bogotá. Se diseñaron funciones específicas como \texttt{calculate_antiguedad()}, que calcula la antigüedad de la publicación a partir del timestamp, y \texttt{transform_property_type()}, que codifica el tipo de propiedad en variables binarias como \texttt{is_house}. Esta distinción resultó fundamental, ya que se evidenciaron diferencias significativas en variables estructurales entre apartamentos y casas, tales como área cubierta y número de ambientes.

\subsection{Limpieza y Tratamiento de Valores Faltantes}

Se implementó la función \texttt{clean_dataset()}, encargada de realizar un filtrado y estandarización rigurosos del conjunto de datos. Esta función eliminó variables irrelevantes como \texttt{city}, \texttt{surface_total} y \texttt{rooms}, las cuales presentaban alta colinealidad o valores faltantes sin estructura sistemática. Posteriormente, se crearon nuevas variables como \texttt{antiguedad} y \texttt{is_house}, y se homogeneizaron los nombres de columnas para facilitar el pipeline de modelado.

La imputación de valores faltantes se realizó utilizando la mediana para variables continuas, una estrategia robusta ante outliers. Por ejemplo, en la variable \texttt{bathrooms}, la imputación logró recuperar observaciones clave sin distorsionar la distribución empírica:

\subsection{Análisis Descriptivo y Selección de Variables}

Se incorporaron variables de distinta naturaleza: estructurales (como \texttt{bedrooms}, \texttt{bathrooms}), geográficas (latitud y longitud), textuales (procesadas desde la descripción del inmueble) y externas (distancias geoespaciales).

\subsubsection{Variables de Texto}

Se desarrollaron funciones personalizadas como \texttt{limpiar_texto()} y \texttt{procesar_datos()} para extraer información relevante a partir de la descripción del inmueble. Estas funciones generaron tres variables clave:

\begin{enumerate}[label=\arabic*.]
\item \textbf{\texttt{nivel_premium}}: variable ordinal que cuenta la presencia de hasta 5 términos asociados con lujo y exclusividad (\textit{jacuzzi, mármol, terraza, vigilancia, etc.}).
\item \textbf{\texttt{nivel_completitud}}: proporción (0–1) de hasta 12 espacios funcionales detectados en el texto (\textit{cocina, estudio, patio, etc.}).
\item \textbf{\texttt{nivel_venta_inmediata}}: contador de hasta 3 términos indicativos de urgencia o promoción (\textit{remate, oportunidad, ganga}).
\end{enumerate}

\section{Modelos y Resultados}

Tras evaluar modelos como regresión lineal, Elastic Net, árboles de decisión, Random Forest y redes neuronales, XGBoost se identificó como el de mejor desempeño para esta tarea, lo cual concuerda con hallazgos recientes \cite{chen2016xgboost}.

\subsection{Modelo y Entrenamiento}

Se utilizó XGBoost, entrenado con el paquete \texttt{caret} en R, empleando validación cruzada de 5 pliegues y búsqueda en cuadrícula sobre hiperparámetros:

\begin{itemize}
    \item \texttt{nrounds} = [500, 1000, 1500]
    \item \texttt{eta} = [0.01, 0.05, 0.1]
    \item \texttt{max\_depth} = [4, 6, 8]
    \item \texttt{gamma} = [0, 0.1, 0.2]
    \item \texttt{subsample}, \texttt{colsample\_bytree} = [0.7, 0.9], [0.6, 0.8]
\end{itemize}

La métrica de optimización fue el RMSE, y la variable objetivo fue \(\log(1 + \text{price})\).

\subsection{Resultados}

El modelo final presentó:

\begin{itemize}
    \item RMSE en entrenamiento: \textasciitilde 99,444,630.02
    \item \(R^2\) en entrenamiento: 0.9078
\end{itemize}

Estos resultados indican una buena capacidad del modelo para capturar la variabilidad del precio de las propiedades en Bogotá, especialmente en la zona de Chapinero.


\section{Conclusión}

Este proyecto demuestra el potencial de los modelos de \textit{machine learning} para predecir precios inmobiliarios a partir de datos estructurados, textuales y espaciales. La integración de diferentes fuentes de información en un pipeline reproducible permitió capturar características relevantes que influyen en el valor de una propiedad urbana.

\begin{itemize}
    \item La incorporación de variables espaciales (\textit{distancia a parques, universidades, estaciones de transporte y comercios}) mejoró la capacidad explicativa del modelo al capturar externalidades positivas asociadas a la ubicación.
    \item Las variables de texto, derivadas mediante procesamiento léxico de las descripciones, ofrecieron información complementaria sobre el nivel de lujo, completitud y urgencia de venta, lo que aportó valor predictivo adicional.
    \item El modelo \texttt{xgboost} con transformación logarítmica de la variable objetivo mostró un desempeño sobresaliente, con un \(R^2\) superior al 0.90 y un error cuadrático medio aceptable considerando la escala de los precios.
    \item La estructura modular del proyecto y el uso de rutas relativas, junto con la documentación explícita, garantizan su adaptabilidad a nuevas ciudades o mercados.
\end{itemize}

Como trabajo futuro, se recomienda:

\begin{itemize}
    \item Incorporar información catastral o de escrituras para validar precios reales y reducir sesgos derivados de precios publicados.

\end{itemize}

En suma, se evidencia que el uso conjunto de técnicas de ciencia de datos, datos abiertos (OpenStreetMap) y procesamiento de lenguaje natural puede aportar soluciones efectivas y escalables para el análisis del mercado inmobiliario urbano en Colombia.
